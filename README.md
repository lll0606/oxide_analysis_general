# oxide_analysis_general

'oxide_analysis_general' is a toolkit for analyzing complex metal-oxide systems (e.g., Pt/CeO2-x).
It implements a workflow that starts from **database preparation and physical inspired feature construction**, followed by **model training and visualization**.
ps. This package is designed with clear separation of steps, so that components (such as, database preparation, feature construction and analysis, model traning, visualization, validation) can be reused or extended in other complex material systems.
